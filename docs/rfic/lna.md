
# 低噪声放大器 LNA 学习笔记

## 一、LNA 的作用

低噪声放大器（Low Noise Amplifier）是
射频接收机前端的重要模块。

主要作用：

1. 放大接收到的微弱射频信号。
2. 尽量减少额外引入的噪声。
3. 实现输入阻抗匹配。
4. 保持良好的线性度。

## 二、LNA 的主要性能指标

| 参数 | 含义 |
|---|---|
| Gain | 增益 |
| NF | 噪声系数 |
| S11 | 输入反射系数 |
| IIP3 | 输入三阶截点 |
| P1dB | 1dB 压缩点 |
| Power | 功耗 |

## 三、级联噪声公式

Friis 公式：

$$
F_{\mathrm{total}} =
F_1 + \frac{F_2-1}{G_1}
+ \frac{F_3-1}{G_1G_2}
$$

其中：

- F 表示线性噪声因子。
- G 表示线性功率增益。
